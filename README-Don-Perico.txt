GET STARTED
1. Download and extract this ZIP on a computer.
2. Open index.html in a browser to preview the website.
3. Give the whole folder to your web designer, or edit index.html (text and links) and style.css (colors, layout and mobile styling) in a text editor.

FILES
index.html — complete one-page website
style.css — responsive styling
food.jpg — current food photograph
README-Don-Perico.txt — these instructions

This is editable HTML/CSS source, not a drag-and-drop editor. No installation or build step is required. Keep all files together. Google Fonts loads online; fallback fonts work offline. A developer can upload the three website files to static web hosting and connect a domain you own. Do not replace an existing restaurant website without its owner's approval.

Editing this package does not change the currently hosted ChatGPT Site. This package contains no account credentials, passwords, or access to John-Michael's account. The existing hosted site remains private; its editing invitations were unsuccessful.
